# De dónde sale esta skill

Instalada a mano el 17/09/2026 desde https://github.com/Leonxlnx/taste-skill
(carpeta `skills/taste-skill`, licencia MIT, incluida al lado).

El instalador oficial es `npx skills add https://github.com/Leonxlnx/taste-skill
--skill "design-taste-frontend"`, pero ejecuta código de terceros. Aquí se copió
el fichero directamente, que hace lo mismo sin ejecutar nada.

Antes de instalarla se revisó: es markdown puro, no trae scripts ni binarios,
no pide claves ni variables de entorno y todos sus enlaces apuntan a la
documentación de sistemas de diseño reales (MDN, shadcn, Radix, Material,
Fluent, Carbon, GOV.UK, USWDS, Apple HIG).

Para actualizarla, volver a copiar el SKILL.md de ese repositorio.
